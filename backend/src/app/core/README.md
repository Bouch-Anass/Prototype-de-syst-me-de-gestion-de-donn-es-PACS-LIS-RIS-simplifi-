# Socle commun

Lot A. Configuration typée et validée, corrélation de requêtes, erreurs communes, dépendances d'accès et horloge testable.

Aucun modèle clinique ni appel spécifique à Orthanc ici. Les secrets sont fournis par l'environnement et ne sont jamais journalisés.

Une configuration manquante entraîne un échec explicite au démarrage, pas l'utilisation d'un mot de passe par défaut.
