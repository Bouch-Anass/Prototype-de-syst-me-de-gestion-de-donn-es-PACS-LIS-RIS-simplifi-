# Client Orthanc

Lot C. Implémenter le [contrat imagerie](../../../../../contracts/imaging.md).

Prévoir un client injecté, des délais configurables, des erreurs normalisées et des tests avec doubles réseau. Aucune credential ne traverse le contrat frontend.

Première preuve : récupération de métadonnées d'une étude synthétique et gestion contrôlée d'un timeout.
