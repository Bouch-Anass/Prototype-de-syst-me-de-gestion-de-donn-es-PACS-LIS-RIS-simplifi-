# Simulateur LIS

Lot B. Génère et envoie les messages du profil HL7 retenu, à partir du manifeste synthétique commun.

Prévoir des scénarios nommés : nominal, missing-crp, duplicate, conflicting-id, corrected et unknown-patient. Les options de lancement et le transport seront ajoutés avec T05.

Le simulateur permet la répétition d'un identifiant de message pour tester le rejeu, tout en générant un nouvel identifiant pour une véritable correction.
