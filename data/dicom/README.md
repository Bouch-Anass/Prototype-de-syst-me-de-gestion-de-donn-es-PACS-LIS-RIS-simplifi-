# Fixtures DICOM

Lot C. Aucun fichier DICOM n'est inclus dans ce squelette.

Le premier jeu doit être généré synthétiquement, avec PatientID, domaine convenu, accession et Study Instance UID cohérents avec le manifeste. Les valeurs fixes ne sont réutilisées que dans le scénario isolé.

Documenter l'outil de génération, les paramètres, le nombre de séries/instances et les conditions d'usage. Les fichiers générés vont dans `data/generated/` et sont ignorés par Git.

Ne pas ajouter arbitrairement des fichiers téléchargés sans vérification de provenance, licence et données identifiantes.
