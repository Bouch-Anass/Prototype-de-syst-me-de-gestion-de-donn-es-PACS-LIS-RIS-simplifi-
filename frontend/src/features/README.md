# Fonctionnalités d'interface

Dossiers proposés à créer avec les premiers écrans : `auth/`, `patients/`, `encounters/`, `laboratory/`, `radiology/` et `imaging/`.

Chaque fonctionnalité possède ses composants, logique d'écran et tests. Les imports de mocks restent réservés au développement et aux tests.

Le texte « Résultat manquant » est distinct de « Service indisponible ». Une valeur nulle n'est jamais convertie en zéro pour simplifier l'affichage.
